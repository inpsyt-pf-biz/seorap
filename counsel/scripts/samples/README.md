# 연습용 구글시트 파일 (가짜 응답)

[구글시트 가져오기] 창을 연습할 때 쓰는 파일이다. 열 이름은 현행 구글폼 신청서와 같고, 응답 내용은 모두 지어낸 값이다
(이름은 시드 데이터와 겹치지 않는 가명, 전화번호는 국번 0000).

| 파일 | 신청서 | 줄 수 | 확인할 수 있는 것 |
| --- | --- | --- | --- |
| `sample-test-main.csv` | 검사 메인 | 5 | 여러 줄로 쓴 신청 이유, 따옴표가 든 답, "상담 종료" 체크 1건, 민감정보 칸, 담당자 메모 |
| `sample-group-buy.csv` | 공동구매 | 3 | 의미 없는 열(19열)·중복 상담 방식 열, "예약 완료" 체크, "상담 종료" 체크 1건 |

같은 파일을 두 번 가져오면 두 번째에는 모두 "이미 있는 건"으로 건너뛴다.
실제 신청자 응답 파일은 로컬 시안에 올리지 않는다.
