# MVP-0 가정

시안은 아래 기본값으로 만들었습니다. 답이 다르면 "바뀌는 곳"만 고칩니다.

| # | 가정 | 기본값 | 다르면 바뀌는 곳 |
|---|---|---|---|
| M1 | 상담 유형 분류 | 개인 · 부부·커플 · 가족 · 아동·청소년 · 놀이치료 · 검사 해석 (6종) | 마이그레이션 CHECK, `core/centers.ts`, `core/copy.ko.ts` (`core/centers.test.ts`가 두 곳을 대조) |
| M2 | 센터 상태 | 입점 준비 · 운영 중 · 신규 배정 중지 · 계약 종료 (4종). 신규 배정 중지 센터도 진행 중인 건은 계속 처리 | 같음 |
| M3 | 센터는 지우지 않는다 | 끝난 센터는 "계약 종료"로 남긴다. 삭제 기능 없음 | 삭제 함수 추가 |
| M4 | 센터명은 겹치지 않는다 | 대소문자를 무시하고 같은 이름 등록을 막는다 | `centers_name_unique` 인덱스 |
| M5 | 연락처 형식 | 숫자와 `-`로 8~20자. 대표번호는 유선·070도 받고, 휴대폰 형식으로 바꾸지 않는다 | 마이그레이션 CHECK, `validateCenterInput` |
| M6 | 센터 정보 관리 권한 | 인싸이트 관리자만 등록·수정. 담당자는 보기만 | `counsel.role_caps` 한 줄 |
| M7 | 인싸이트 본사 | 센터 표의 한 행. 목록에 보이지 않고 화면에서 고칠 수 없다 | `listCenters`, `rpc_update_center` |
| M8 | 변경 이력 | MVP-0에는 마지막 수정 시각과 version만 남긴다. 누가 무엇을 바꿨는지는 예약 원장(MVP-1)부터 남긴다 | 이력 표와 트리거 추가 |
| M9 | 담당자 이름·연락처 | 센터당 대표 담당자 1명. 여러 명이면 상담사·직원 레코드(MVP-2)에서 다룬다 | 센터 직원 표 |
