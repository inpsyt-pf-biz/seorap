# 상담 신청서 단계형 화면 · 기타 직접 입력 · 조건부 문항 (11-10)

> 근거: 11-10 피드백 "신청이 쉬워야 한다"(미용실 예약 비유) + 건우님 요청 "토스처럼 입력하면 자동으로 넘어가는 구조",
> "기타는 누르면 그 자리에서 입력", "앞 문항 응답을 다음 문항 제목에 끼워 넣기", "고르지 않고 넘기면 다음 문항도 넘기기".
> 승인: 11-10 "계획 간단히 하고 모두 올려줘".

## 결정 (Claude)

- **기타 답의 모양:** 선택지에 없는 값 하나를 기타 글로 본다(단일: 문자열, 복수: 배열 안 한 개). 원장에는 `기타: 육아`, 제목 끼워 넣기에는 `육아`.
- **끼워 넣기:** 선택지 끝 괄호 설명은 뺀다("대인관계 (예: …)" → "대인관계"). 여러 개는 ", "로 잇는다. 원장에는 고객이 실제로 본 제목을 남긴다.
- **숨은 문항:** 필수여도 묻지 않는다. 숨은 문항에 온 답은 화면이 제출 전에 지우고, 서버는 `unknown`으로 거부한다. 조건은 앞 문항만 가리킬 수 있다(`checkDefinition`이 막음).
- **어드민 미리보기의 한 장 화면**도 같은 숨김 규칙을 따른다.

## 2차 (11-10 건우님 검수 반영)

- **약관은 바텀시트로, 은행 앱처럼 차례로**(건우님 선택 "1번 차례로 시트"): [시작하기] → 약관 1 시트 [동의하기] → 약관 2 시트 [동의하기] → 첫 질문. 시트를 닫으면 시작 화면에 남고, 다시 시작하면 아직 동의하지 않은 약관부터. 시작 화면의 약관 줄을 누르면 그 약관만 시트로 연다. 제공받는 업체 정보는 제3자 제공 시트 안에 둔다. 펼침(보기/접기)과 "모두 동의하고 시작하기"는 없앴다
- **민감정보 약관**도 같은 시트: [동의하고 적기] → 시트 [동의하기] → 질문. 선택 약관이라 시트에 [동의하지 않기]도 있다
- **생년월일**: 신청자 생년월일 칸(`mapsTo: client_birth`)이면 8자리를 다 쓴 뒤 "만 N세"를 보여 주고 0.7초 뒤 넘긴다. 확인 화면에는 "1995. 3. 12. (만 31세)"
- **확인 화면**: 표 대신 흰 카드 하나에 질문(13px 회색) 위 · 답(16px 진하게) 아래, 줄마다 [수정]. 신청 버튼은 바닥에 붙어 늘 보인다
- **템플릿**: "두 분은 어떤 사이인가요?" 삭제(기간 질문이 대신한다), "상담을 신청하신 이유" 장문형(4줄 칸). "상담에서 기대하는 부분"은 건우님 답을 받기 전까지 그대로 둔다
- 알려진 한계: 어드민 신청서 미리보기에서 약관 시트를 열면 미리보기 칸이 아니라 어드민 창 바닥에서 올라온다

## 시험

엔진 규칙은 deno 시험으로 먼저 고정 → 서랍 화면 시험(vitest) → 어드민 화면 시험 → API 통합 시험 → 5178 로컬 화면 검수(휴대폰 폭).

## 3차 이후 (11-10)

- **상담메인 신청서의 정본은 로컬 상담 어드민의 게시판이다.** 건우님이 6판부터 어드민에서 직접 고친다. 미리보기 SQL은 그 게시판 definition 으로 만든다(seedForms.ts 의 SEED_MAIN_FORM 은 5판에 머물러 있고 시험·로컬 시드용).
- 가능 시간대 질문 아래 설명(`availability.helps.start|method|contact`)을 더했다. 어드민 "질문 아래 설명" 칸. 7판: 상담 방식 아래 "대면 상담은 서울시 마포구 홍대입구 인근의 직영 상담센터에서 진행됩니다."
